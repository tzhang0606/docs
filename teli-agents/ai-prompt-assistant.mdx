## Why the prompt matters

Your agent's prompt is the single most important factor in how it performs. It defines the
agent's persona, its objective, how it handles objections, and when it should hand off to a
human. Writing a strong prompt from scratch can be intimidating — so Teli includes a built-in
AI assistant that drafts and refines the prompt for you.

## Using the AI prompt assistant

1. **Open your agent** – From the **AI Agents** page, create a new agent or open an existing one.
2. **Open the AI Assistant** – In the agent editor, click the **AI Assistant** button to open the
   assistant panel.
3. **Describe your goal in plain English** – Tell the assistant what you want the agent to do
   (for example, "qualify inbound mortgage leads and book a call with a loan officer"). You don't
   need to write the final prompt yourself — just describe the outcome.
4. **Generate a draft** – The assistant drafts both the agent's **system prompt** and its
   **starting message** from your description.
5. **Refine iteratively** – Ask the assistant to adjust anything: make the tone friendlier,
   add an objection-handling section, shorten the greeting, or emphasize a specific offer. Each
   request updates the draft.
6. **(Optional) Ground it on a real conversation** – Point the assistant at an existing SMS
   conversation or call transcript so the prompt is based on how your best conversations actually go.
7. **Apply and test** – Click **Apply** to drop the draft into the agent form, then run a test call
   or message to confirm the agent behaves the way you expect before launching a campaign.

## Tips for a stronger prompt

- **Be specific about the objective.** "Book a demo" or "confirm interest in refinancing" gives
  the AI a clear finish line to write toward.
- **Give the assistant context about your business.** The more it knows about your offer and
  audience, the more relevant the draft.
- **Iterate in small steps.** Change one thing at a time so you can see the effect of each edit.
- **Always test before you launch.** A quick test call or SMS reveals issues no prompt review can.
- **Personalize with dynamic variables.** Reference contact data in the prompt using the separate Dynamic Variables drawer in the agent editor (see [Using Dynamic Variables](/teli-agents/dynamic-variables2)).
