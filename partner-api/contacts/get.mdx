---
title: 'Get Contacts'
api: 'GET /v1/contacts/lists/{id}/contacts'
description: 'Get contacts from a list'
---

## Authorizations

<ParamField header="X-API-Key" type="string" required>
  Authentication header
</ParamField>

## Path

<ParamField path="id" type="string" required>
  Contact list unique_id
</ParamField>

## Query Parameters

<ParamField query="user_id" type="string">
  User unique_id (for access control)
</ParamField>

<ParamField query="is_admin" type="boolean">
  If true, admin can view any list in the org. If false/missing, user can only view their own lists.
</ParamField>

<ParamField query="limit" type="integer" default="25000">
  Maximum number of contacts to return. Capped at 25000.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of contacts to skip before returning results. Combine with `limit` to page through large lists.
</ParamField>

```bash
  -H "X-API-Key: YOUR_API_KEY"
```

</RequestExample>

## Pagination

The response includes pagination metadata alongside the `contacts` array:

- `total` — total contacts in the list (not just this page)
- `returned` — number of contacts in this response
- `limit` / `offset` — the values applied to this request
- `has_more` — `true` when more contacts remain beyond this page (i.e. `offset + returned < total`)
